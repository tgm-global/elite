# Eliteworks - Industrial Automation & Robotics website

Static website (HTML/CSS/JS) for GitHub Pages. Fixed header and fixed bottom contact bar on every page.

- Edit `js/config.js` for name, logo, phone, email, forms key, testimonials key, GitHub details.
- Run `python3 _source/build.py` after changes to refresh SEO tags and sitemap.
- Full instructions: `_source/SETUP.md`.
